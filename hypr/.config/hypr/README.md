# Hyprland configuration blueprint

This is a modular Hyprland desktop with daily shortcuts, dynamic wallpaper colours, workspaces, a scratchpad, overview, notifications, screenshots, and laptop controls. This guide explains how to use it and where to safely change it.

Press <kbd>Super</kbd> + <kbd>H</kbd> or <kbd>Ctrl</kbd> + <kbd>H</kbd> for the complete on-screen guide. Press <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> to search every binding Hyprland loads.

> **Super** is the Windows key (or Command on many external keyboards). Both **Super + H** and **Ctrl + H** open the guide.

## Start here: the five-minute tour

1. Press <kbd>Super</kbd> + <kbd>A</kbd>, type an app name, and press Enter.
2. Open a terminal with <kbd>Super</kbd> + <kbd>Return</kbd>; open files with <kbd>Super</kbd> + <kbd>E</kbd>.
3. Switch workspace with <kbd>Super</kbd> + <kbd>1</kbd> … <kbd>0</kbd> or <kbd>Super</kbd> + <kbd>Tab</kbd>.
4. Move a window with <kbd>Super</kbd> + <kbd>Shift</kbd> + a number. Add <kbd>Ctrl</kbd> to move it without following it.
5. Press <kbd>Super</kbd> + <kbd>O</kbd> for the visual workspace overview; use <kbd>Super</kbd> + <kbd>U</kbd> for the scratchpad.
6. Press <kbd>Super</kbd> + <kbd>W</kbd> to select a wallpaper and refresh the desktop palette.

## The configuration flow

[`hyprland.conf`](hyprland.conf) is the active entry point. It loads shared defaults first and then personal overrides. For almost every change, edit **UserConfigs**, never the base files.

```text
hyprland.conf
├── hyprconf/configs/                 shared defaults
│   ├── Keybinds.conf                 core window, workspace, and hardware binds
│   ├── Startup_Apps.conf             session services
│   ├── WindowRules.conf              default app rules
│   └── plugins/hyprtasking.conf         workspace overview
├── hyprconf/UserConfigs/             your safe editing area
│   ├── 01-UserDefaults.conf          apps, editor, search engine
│   ├── UserKeybinds.conf             launchers and personal shortcuts
│   ├── UserSettings.conf             input, layout, and gestures
│   ├── UserDecorations.conf          gaps, borders, blur, opacity
│   ├── UserAnimations.conf           animation settings
│   ├── ENVariables.conf              Wayland, scaling, and GPU variables
│   ├── Startup_Apps.conf             personal autostart items
│   ├── WindowRules.conf              personal per-app rules
│   └── Laptops.conf                  laptop keys and touchpad
├── monitors.conf                     display layout generated by nwg-displays
├── hyprconf/workspaces.conf          workspace-to-monitor rules
├── scripts/                          helpers used by bindings
└── UserScripts/                      wallpaper and personal utilities
```

`hyprland.lua` and `hyprlua/` are an alternate/generated Lua configuration set. This setup currently loads the `.conf` tree above; use it unless you intentionally switch the session entry point.

## Make it yours

Edit one concern at a time, then reload:

```bash
hyprctl reload
```

| Goal | Edit | Change |
| --- | --- | --- |
| Default terminal, files, editor, search provider | [`01-UserDefaults.conf`](hyprconf/UserConfigs/01-UserDefaults.conf) | `$term`, `$files`, `EDITOR`, `$Search_Engine` |
| Personal shortcuts | [`UserKeybinds.conf`](hyprconf/UserConfigs/UserKeybinds.conf) | Add described `bindd` entries |
| Keyboard, pointer, touchpad, layouts, gestures | [`UserSettings.conf`](hyprconf/UserConfigs/UserSettings.conf) | `input`, `touchpad`, `master`, `dwindle`, `gestures` |
| Gaps, blur, borders, opacity | [`UserDecorations.conf`](hyprconf/UserConfigs/UserDecorations.conf) | `general` and `decoration` |
| Animation behaviour | [`UserAnimations.conf`](hyprconf/UserConfigs/UserAnimations.conf) | `animations` block |
| Startup apps | [`Startup_Apps.conf`](hyprconf/UserConfigs/Startup_Apps.conf) | `exec-once = command` |
| Rules for one application | [`WindowRules.conf`](hyprconf/UserConfigs/WindowRules.conf) | Add personal window/layer rules |
| Monitor layout | [`monitors.conf`](monitors.conf) | Prefer nwg-displays; it regenerates this file |

For a new binding, use `bindd` so it is readable in the keybinding search:

```conf
# Super + Shift + V opens your preferred editor
bindd = $mainMod SHIFT, V, open editor, exec, $term -e nvim
```

Avoid duplicating a shortcut already shown by the helper; the result depends on load order and is hard to maintain.

## Displays, laptop, and theming

`monitors.conf` is generated by **nwg-displays**. Use nwg-displays for monitor changes rather than hand-editing generated output. The present configuration has `eDP-1` at 1920×1080 with 1.25 scaling.

`Laptops.conf` handles brightness, touchpad, and vendor keys. If <kbd>Alt</kbd> + <kbd>T</kbd> cannot toggle the touchpad, run `hyprctl devices`, then update `$Touchpad_Device` in that file.

Selecting a wallpaper runs the colour flow. Wallust creates palette files used by Hyprland, Waybar, Rofi, Kitty, SwayNC, and Cava via the templates in `~/.config/wallust/`.

## Startup and troubleshooting

At login the setup starts the wallpaper daemon, notification centre, Waybar, network tray, clipboard history, Polkit helper, Hypridle, and Hyprsunset. Its shortcuts expect tools including `kitty`, `nautilus`, `rofi`, `anyrun`, `yad`, `hyprshot`, `swappy`, `cliphist`, `waybar`, `swaync`, `hyprlock`, and `hypridle`.

If something is not working:

1. Run `hyprctl reload` after every configuration edit and read its errors.
2. Use <kbd>Super</kbd> + <kbd>Alt</kbd> + <kbd>R</kbd> to refresh bar and menus.
3. Use <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> to confirm a binding loads.
4. Run `hyprctl devices` to verify monitor and input-device names.
5. Inspect the current boot with `journalctl --user -b | rg -i 'hypr|waybar|swaync'`.

## Workspace overview

Hyprtasking is configured in [`hyprtasking.conf`](hyprconf/configs/plugins/hyprtasking.conf). Toggle it with <kbd>Super</kbd> + <kbd>O</kbd> or a four-finger upward swipe. After a Hyprland or plugin update, run:

```bash
hyprpm update
hyprpm reload -n
```

If it does not open, check `hyprpm list` and enable the installed plugin if needed.
